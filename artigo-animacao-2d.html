Como Criar Animações 2D Automáticas com Claude Code e Python (Passo a Passo)

Por Equipe MDC • Guia Completo

Todo mundo sabe que o YouTube é uma excelente plataforma para gerar renda. Mas e se você pudesse ter um canal 100% automático, com edição cinematográfica e perfeitamente alinhada ao seu roteiro?

Neste artigo, vamos desvendar o método para criar animações 2D incríveis utilizando o Claude Code em conjunto com a linguagem Python e uma ferramenta chamada Golpo (ou Goku). Esse formato é ideal para canais "Dark" (onde você não aparece) ou para qualquer projeto de conteúdo que demande animações rápidas.

Vamos ao passo a passo de como configurar a sua própria "fábrica" de animações:

1 Preparando o Terreno (Baixando Claude e Python)

A primeira coisa que você precisa fazer é baixar as ferramentas principais:

  • Acesse o site do Claude e baixe o aplicativo para o seu computador (como a versão para Windows).
  • Em seguida, acesse python.org/download e baixe a última versão do Python. A instalação é bem simples, basta executar o arquivo baixado e ir aceitando os termos até concluir.

2 Configurando as Requisições no Terminal

Com o Python instalado, você precisará abrir o "Prompt de Comando" (cmd) do seu computador executando-o como administrador.

  • Use o comando CD seguido do diretório de instalação do Python para navegar até a pasta correta.
  • Cole o comando necessário para instalar alguns user requests (requisições de usuário) – essenciais para as automações de conteúdo funcionarem.

3 Instalando o Node.js e o Claude Code

Para que o Claude Code rode perfeitamente na sua máquina, a instalação do Node.js é obrigatória.

  • Baixe e instale o Node.js (basta avançar na instalação com as configurações padrão).
  • De volta ao terminal, cole o comando de instalação do Claude Code.
  • Dica de verificação: Para garantir que tudo deu certo, digite no terminal node --version e python --version (deve aparecer algo como Python 3.14.3).

4 Criando e Iniciando o Seu Projeto

Agora, crie uma nova pasta no seu computador (por exemplo, chamada "projeto") onde as suas criações ficarão salvas.

  • Abra o terminal como administrador novamente, use o comando CD com o caminho dessa nova pasta e digite cloud.
  • A interface do Claude Code vai carregar. Faça o login utilizando sua conta; ele abrirá uma aba no navegador para você autorizar e depois retornará pronto para uso.

5 Adicionando a "Skill" de Animação 2D

O grande segredo dessa automação são as skills (habilidades) instaladas no Claude Code.

  • No terminal do Claude Code, cole os comandos de instalação e adicione a skill Golpo/Goku, que é a responsável por gerar as animações 2D.
  • Escolha a opção de instalar apenas para o seu usuário ("user scope") e digite o comando reload plugins para ativar a ferramenta.

6 Gerando a Chave de API

Para que a sua máquina consiga se comunicar com o servidor remotamente sem precisar que você faça login em sites toda hora, você precisa de uma Chave de API.

  • Acesse o site do Golpo/Goku e crie uma conta gratuita.
  • Gere a sua chave de API e vincule-a no chat do terminal.

7 A Mágica Acontece (Gerando a Animação!)

Tudo pronto! No próprio terminal do Claude Code, você agora pode digitar o seu prompt pedindo o vídeo.

"Crie uma animação de 10 segundos em um quadro branco usando golp skill sobre a explosão de Chernobyl. Tenha certeza de usar Python e não Python 3".

O sistema vai processar o pedido remotamente e baixar o arquivo de vídeo diretamente na sua máquina, além de gerar um link de hospedagem para você visualizar o resultado final!

💡 Dica Extra: Caso você ache a configuração do terminal muito complexa, você também pode criar essas animações diretamente pelo site do Golpo, digitando os prompts manualmente por lá. No entanto, usar o Claude Code deixa o fluxo muito mais automático!

As animações podem ser utilizadas tanto para vídeos curtos (Shorts) quanto para projetos longos e autorais. O céu é o limite quando você domina as ferramentas de IA certas!
